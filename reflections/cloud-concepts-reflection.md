Cloud Concepts Reflection

Cloud computing is a big part of my daily life because many of the apps I use work through the internet. Three cloud services I use regularly are Google Drive, Canva, and Facebook Messenger.

Google Drive helps me save my files online so I can access them anytime and from any device. It is a Software as a Service (SaaS) because I use the application without managing the system behind it. It also uses the Public Cloud model since anyone can create an account and use the service online.

Canva is another cloud service I often use for making presentations, posters, and other designs. It is also a SaaS application because everything is available through a web browser or mobile app. Canva is part of the Public Cloud because it is open to users around the world.

Facebook Messenger is my main app for chatting with friends, classmates, and family. It is also a SaaS because Meta provides the messaging service online. Messenger uses the Public Cloud since it is available to millions of users through the internet.

Version control is very important when working on cloud projects because it keeps track of every change made to files. If someone makes a mistake, it is easy to go back to an earlier version. Git and GitHub help people work together by allowing them to share code, review changes, and manage different versions of a project. This makes teamwork easier, reduces errors, and helps keep cloud projects organized and up to date.
